# Changelog

## v2.0.0 (2026-02-25)

Major overhaul of the RAG system with hybrid search, contextual retrieval, and incremental scraping.

### Added

- **Incremental scraper** (`incremental_scraper.py`): Sitemap-driven updates in 2-10 minutes, replacing the 8+ hour BFS crawler
- **Contextual chunk enrichment**: Metadata-derived prefixes on every chunk using Anthropic's Contextual Retrieval technique (35% fewer retrieval failures)
- **BM25 hybrid search**: Okapi BM25 keyword index with Reciprocal Rank Fusion, reducing retrieval failures by 49% over vector-only search
- **FastMCP server**: Migrated from low-level Server class to FastMCP with Pydantic schemas and tool annotations
- **4th MCP tool**: `get_index_stats` for index health monitoring
- **Central configuration**: `cyberark_rag/config.py` Settings class with environment variable overrides
- **stderr-only logging**: `cyberark_rag/logging_config.py` prevents log messages from corrupting MCP JSON-RPC on stdout
- **Query expansion**: 80+ CyberArk-specific term groups (SPIFFE/SPIRE, K8s/OpenShift, etc.)
- **Intent-aware re-ranking**: 5 intent types (how-to, explanation, reference, troubleshooting, general) with content-type boost multipliers
- **Content classification**: Automatic chunk typing (procedural, conceptual, reference, code-example)
- **Product alias resolution**: 22+ canonical products with 60+ aliases, loaded from `product_aliases.yaml`
- **pytest suite**: Comprehensive tests replacing the custom test harness
- **Automation scripts**: `scripts/update.sh` and `scripts/full_rebuild.sh`

### Changed

- Default chunk size increased from 500 to 800 tokens
- Default embedding model changed to `BAAI/bge-large-en-v1.5` (1024 dims, up from 384)
- MCP tool names now prefixed with `cyberark_rag_` to prevent collisions
- All hardcoded paths removed; configuration via env vars

### Removed

- Hardcoded paths to developer machine (`/Users/joe.garcia/...`)
- Custom test framework (`test_mcp.py`)
- Manual schema definitions in MCP server (now auto-generated by FastMCP)
